# کتابچهٔ جامع حکمرانی ایران — Iran Civic Atlas

هدف پروژه: **ساخت یک مرجع کامل از ساختار حکمرانی ایران، از بالا تا پایین‌ترین واحد**، به‌طوری که هیچ بخشی از کشور بی‌مسئول باقی نماند، در سه لایهٔ به‌هم‌پیوسته:

1. **تقسیمات کشوری:** استان ← شهرستان ← بخش ← دهستان ← شهر ← آبادی/روستا (با کدهای رسمی و منبع)
2. **نهادها:** نهادهای کلی (قوا، نهادهای حکومتی، نیروهای مسلح) + نهادهای بخش‌های تخصصی + نهادهای برون‌مرزی
3. **افراد:** مسئول هر واحد کوچک‌تر + جانشین رسمی + جانشینان احتمالی، با تاریخ انتصاب و منبع

**ضابطهٔ کیفی این پروژه:** هیچ جزئیاتی که هدف تحقیق باشد حذف یا «خلاصه» نمی‌شود؛ هر یافته با نشانی منبع و برچسب وضعیت تأیید ثبت می‌شود (`✅` تأییدشده، `⚠️` نیازمند راستی‌آزمایی، `❌` دست‌نیافتنی/خلأ).

### بازتولید خروجی‌ها
```bash
python3 scripts/build_data.py       # فاز ۱: data/ + docs/01-divisions/03-tree/
# فصل ۹ — ترتیب مهم:
python3 scripts/update_officials.py # ۱) اعمال نتایج پژوهش روی فایل‌های ۱۲ گروه
python3 scripts/build_officials.py  # ۲) بازتولید data/officials.csv از همان فایل‌ها
```
خروجی‌های فاز ۱ با شمارش‌های رسمی برابرند: `31 / 484 / 1193 / 2777 / 1481 / 191 / 99317`.
خروجی فصل ۹: `519` ردیف (۳۱ استاندار + ۴۸۸ ردیف شهرستان/واحد فرعی).

## منابع کلیدی
- **دادهٔ ساختاری:** فایل جغرافیایی سالانهٔ مرکز آمار ایران ۱۴۰۴ (`geo_1404.xlsx`) از مخزن https://github.com/Hameds/IranCountryDivisions (مجوز MIT، همراه با سند استاندارد آدرس‌دهی `geo_standard.pdf`)
- **تاریخچه و آمار تفکیکی:** `amar.org.ir` (از این محیط قابل واکشی نبود)، `moi.ir`، آمارنامه‌های استانی، ایران‌استاتیس
- **متن قوانین:** `qavanin.ir` (مصوبهٔ ۱۳۷۷ شورای عالی اداری و قانون شوراها)، صفحات «قوانین» استانداری‌ها
- **نام مقامات فعلی:** `dolat.ir`، `president.ir`، سایت استانداری‌ها/فرمانداری‌ها/شهرداری‌ها، `villagemanagement.ir`، و خبرگزاری‌های ایرنا/فارس/تسنیم/ایسنا/مهر

فهرست کامل نشانی‌ها در اسناد هر فصل و `booklet/index.md` آمده است.

## خلأها و کارهای باقی‌مانده (شفاف)
1. **ثبت نام مسئولان همهٔ واحدها (فاز ۳):** ۳۱ استاندار، ۴۸۴ فرماندار، ≈۱٬۱۹۳ بخشدار، ۱٬۴۵۱ شهردار، ≈۳۶٬۰۰۰ دهیار و اعضای ≈۲۶ هزار شورای روستا/بخش — هیچ فهرست ملی رسمی وجود ندارد و باید استان‌به‌استان از منابع بخش B3 سند `03-officials` جمع شود. **وضعیت کنونی:** لایهٔ استاندار و فرماندار در `docs/03-officials/09-unit-files/` (۱۲ فایل) و `data/officials.csv` ثبت شد؛ ۵۱۷ ردیف نام مسئول دارد و **۲ ردیف هنوز بدون نام منتشرشده** است (ترکمانچای، ماژین). پس از موج‌های ۵ و ۶ و جست‌وجوی عمیق تکمیلی (۳۰ آبان ۱۴۰۵) هیچ برچسب `⚠️` در فصل ۹ نماند: ۴۳۳ `✅` و ۸۶ `⏳` (بیشترین باقی‌مانده: اصفهان ۷، آذربایجان غربی ۶، کرمان ۶، سیستان و بلوچستان ۶). ستون‌های جانشین رسمی/احتمالی و سطوح بخش تا آبادی خالی‌اند.
2. **راستی‌آزمایی برچسب‌های `⚠️`** در `docs/02-institutions/04-national.md` (حدود ۳۰ مورد: رؤسای سازمان‌ها، فرماندهان، دبیر شورای نگهبان و…).
3. **اصلاحیهٔ ۱۴۰۳ قانون شوراها** — مواد ۵۳ و ۷۱ (به‌ویژهٔ آستانهٔ ۲۰۰ هزار نفر برای حکم شهردار) باید با متن روز مقایسه شود.
4. **خلأهای برون‌مرزی:** فهرست رسمی سفارت‌ها از `mfa.gov.ir` (سایت از این محیط باز نشد)، فهرست کامل نمایندگی‌های دائم نزد سازمان‌های بین‌المللی، دایرکتوری دفاتر خارجی هلال احمر.
5. **به‌روزرسانی داده:** نسخهٔ داده ۱۴۰۴ (۴۸۴ شهرستان) است؛ گزارش‌های آبان ۱۴۰۵ از ۴۸۵ شهرستان خبر می‌دهند — با انتشار فایل جغرافیایی ۱۴۰۵ باید `scripts/build_data.py` دوباره اجرا شود. همچنین ارتقای اخیر بخش میمه (اصفهان) به شهرستان در مهر ۱۴۰۵ باید در داده منعکس شود.
6. **مراکز شهرستان‌های تازه** (کرخه، لاشار، گلشن، میان‌جلگه، جازموریان، هلیلان، سیمرغ، جرقویه و…) و نام رسمی شهرستان چاه‌بهار/چابهار باید از ادارهٔ کل تقسیمات کشوری استعلام شود.
